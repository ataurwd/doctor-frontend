# Dr. Md. Kamrul Hasan Sajib – Official Medical Website (Frontend)

Next.js frontend application for **Dr. Md. Kamrul Hasan Sajib**, Rheumatology, Arthritis & Joint Pain Specialist (MBBS, BCS Health, MD Rheumatology, ECRD Switzerland, FACR USA).

## Tech Stack
- **Framework:** Next.js 15 (App Router, Server & Client Components)
- **Styling:** Tailwind CSS v4
- **Localization:** Bilingual (Bengali `bn` & English `en`)
- **Bangla Typography:** Li Ador Bangla font integration
- **Icons:** SVG icon system

## Features
- Fully responsive design (Mobile, Tablet, Desktop)
- 2-Column executive service & clinical speciality cards with symptom indicators
- Chambers schedule & interactive booking requests
- Patient Education library with category filtering & handouts
- Secure API connection to Node.js backend

## Getting Started

1. Clone repository:
   ```bash
   git clone https://github.com/ataurwd/doctor-frontend.git
   cd doctor-frontend
   ```

2. Install dependencies:
   ```bash
   npm install
   ```

3. Configure environment:
   ```bash
   cp .env.example .env.local
   ```

4. Start development server:
   ```bash
   npm run dev
   ```
   Open [http://localhost:3000](http://localhost:3000) in your browser.
